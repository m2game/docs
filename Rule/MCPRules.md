# MCPRules.md

使用しているMCP一覧の情報

## Computer Use

- 使用許可
    - 禁止 
- 概要
    - AIが画面上のカーソルとキーボードを使ってアプリケーションを操作する
    - 画面上で紫色のカーソルが動く
    - マウスとキーボードに相当する画面操作を行う
    - この環境ではMCP形式のツールとして呼び出す

- ルール
    - Unityの画面検証では開いている対象パネルを最大化する
        - パネルの位置を毎回同じ位置に揃える
        - 対象UIの全体を正しく確認できる表示状態にしてから検証する
    - 操作中に別の操作手段へ切り替えない
        - 操作に失敗した場合も同じ操作手段のまま原因を確認して再実行する

## UnityMCP (mcp__mcp_unity)

- 使用許可
    - 人間が許可した場合のみ 

- 概要
     AIがUnityEditorを直接操作する場合に使用する

- ルール
    - MCPを使う前に、lsof -nP -iTCP:8090 -sTCP:LISTEN で Unity MCP サーバーの疎通チェックを行う
    - 疎通チェックの終了コードが 
        0 → UnityMCPを使う
        0以外 → UnityMCPを使えませんでした と返してチャットを終わること
    - コンパイル確認と画面確認は人間側で行う
        - エラー時はエラー文章を人間様に貼ってもらうこと
