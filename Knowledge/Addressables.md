# Addressables.md

## 環境構築手順

- Addressables Groupsを開く
  - WindowからAsset Managementを開く
    - AddressablesからGroupsを選択する
- Addressablesの設定を作成する
  - Create Addressables Settingsを実行する
  - 旧AssetBundleの変換確認ではIgnoreを選択する
- JSON形式のカタログを有効にする
  - Addressables GroupsのToolsからInspect System Settingsを選択する
  - Addressable Asset SettingsのCatalogを開く
  - Enable Json Catalogを有効にする
- JSONカタログの読み込みに成功することを確認する
